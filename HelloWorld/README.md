# Overview

For this project, I made a simple C++ program that displays "Hello World!" in the console. I wanted to use this project to get more familiar with C++ and learn how a basic C++ program is put together.

The purpose of this software is mainly to practice the basics of C++, like using `main()`, `std::cout`, and running a program through Visual Studio.

[Software Demo Video](https://youtu.be/nigxzSfCuDk)

# Development Environment

I used **Visual Studio Community** on Windows to make this program. I used Visual Studio to write the code, build the program, and run it.

The programming language I used was **C++**.
