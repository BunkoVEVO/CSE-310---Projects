# C++ Hangman Game

## Overview

This project is a simple command-line Hangman game written in C++.

The player is given a hidden word and must guess the letters one at a time. The
player can make up to six incorrect guesses before losing the game.

The program demonstrates several C++ programming concepts including variables,
conditionals, loops, functions, classes, vectors, file input, random numbers,
and user input.
